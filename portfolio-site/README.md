# Mou Rakshit Portfolio Site

This directory is the source-controlled version of Mou Rakshit's professional Data & AI portfolio.

## Vercel configuration

- Project: `mou-rakshit`
- Git repository: `mourakshit-northville/dayofdata_website`
- Production branch: `agent/portfolio-site-source`
- Root directory: `portfolio-site`
- Framework preset: Other / static HTML
- Build command: none
- Output directory: `.`

## Featured AI architecture projects

The portfolio links directly to four reference projects maintained in the `agent/ai-architecture-portfolio` branch:

1. Enterprise Agentic AI Reference Architecture
2. Databricks AI Governance Reference
3. Microsoft Fabric Real-Time Agentic Intelligence
4. Governed Conversational BI with Databricks Genie

The site is intentionally separated from the Day of Data production branch so portfolio changes do not alter the Day of Data website.
