## AI architecture portfolio

The [`ai-architecture-portfolio`](./ai-architecture-portfolio/README.md) collection focuses on practical enterprise patterns for Applied AI, Agentic AI, governance, real-time intelligence, Databricks, and Microsoft Fabric.

### Featured reference projects

- **[Enterprise Agentic AI Reference Architecture](./ai-architecture-portfolio/enterprise-agentic-ai-reference/README.md)** — governed context, agent orchestration, approved tools, evaluation, and human approval.
- **[Databricks AI Governance Reference](./ai-architecture-portfolio/databricks-ai-governance/README.md)** — Unity Catalog, Unity AI Gateway, model/agent/MCP governance, MLflow, policy, and auditability.
- **[Microsoft Fabric Real-Time Agentic Intelligence](./ai-architecture-portfolio/fabric-realtime-agentic-intelligence/README.md)** — Eventstream, Eventhouse, KQL, Activator, MCP, real-time reasoning, and governed actions.

Each project includes a Mermaid architecture diagram, design rationale, production considerations, and small illustrative Python examples where useful.
